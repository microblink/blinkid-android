DriverLicenseDetailedInfoCompleteness

data class DriverLicenseDetailedInfoCompleteness<StringType : Parcelable, DateType : Parcelable>(val restrictions: StringType?, val endorsements: StringType?, val vehicleClass: StringType?, val conditions: StringType?, val vehicleClassesInfo: List<VehicleClassInfoCompleteness<StringType, DateType>>?) : Parcelable

Describes completeness information for driver license detailed info.

This structure reports which driver license “detailed info” fields were present and successfully extracted, along with completeness information for each field. It also includes per-vehicle-class entries (if available), which describe extraction completeness for individual vehicle class records.
